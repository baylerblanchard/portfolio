## 🛠 Technologies Used

*   **Frontend:** HTML5, CSS3 (Custom Properties/Variables), Vanilla JavaScript
*   **Design:** Responsive Mobile-First approach, Flexbox & CSS Grid
*   **Features:**
    *   **Dark/Light Mode:** Persisted user preference using `localStorage` and system `prefers-color-scheme`.
    *   **Responsive Navigation:** Custom hamburger menu with animation.
    *   **Accessibility:** Semantic HTML and ARIA labels.

## ⚙️ Local Development

To run this project locally:

1.  **Clone the repository**
    ```bash
    git clone https://github.com/baylerblanchard/portfolio.git
    ```

2.  **Navigate to the project folder**
    ```bash
    cd portfolio/personal\ website
    ```

3.  **Launch the site**
    *   Open `index.html` in your browser.
    *   OR use a live server extension (VS Code Live Server) for hot reloading.
